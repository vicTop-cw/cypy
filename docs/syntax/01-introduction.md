# Cypy 语言语法规范 - 介绍与设计理念

## 1. 语言概述

**Cypy**（Cython + Python Syntactic Sugar）是一种基于 Python 语法体系的编译型语言，通过 Cython 作为后端实现性能提升，同时引入静态类型系统和丰富的语法糖，在保持 Python 兼容性的前提下提供更好的性能和开发体验。

### 1.1 核心定位

| 维度 | 描述 |
|------|------|
| **目标用户** | 需要高性能 Python 代码的开发者、需要 C 级性能但希望用 Python 语法的工程师 |
| **设计理念** | Python 超集 + 渐进式类型 + Cython 编译 |
| **性能目标** | 接近 C 语言的执行速度，比纯 Python 快 10-100 倍 |
| **兼容性** | 完全兼容 Python 3.9+ 语法和标准库 |

### 1.2 架构层次

```
┌─────────────────────────────────────────────┐
│              Cypy 源码 (.cypy)              │
│  Python 语法 + 类型注解 + Cypy 语法糖       │
└─────────────────────┬───────────────────────┘
                      │ cypyc 转译器
                      ▼
┌─────────────────────────────────────────────┐
│              Cython 代码 (.pyx)             │
│  cdef/cpdef 函数 + 静态类型 + C 特性         │
└─────────────────────┬───────────────────────┘
                      │ Cython 编译器 (cythonize)
                      ▼
┌─────────────────────────────────────────────┐
│                  C 代码 (.c)                │
│  C 函数 + Python C API 调用                  │
└─────────────────────┬───────────────────────┘
                      │ C 编译器 (MSVC/GCC/Clang)
                      ▼
┌─────────────────────────────────────────────┐
│               二进制扩展 (.so/.pyd)          │
│  可直接导入的 Python 扩展模块                │
└─────────────────────────────────────────────┘
```

## 2. 设计原则

### 2.1 核心原则

| 原则 | 说明 |
|------|------|
| **Python 超集** | 任何合法的 Python 代码都是合法的 Cypy 代码，无需修改即可编译运行 |
| **渐进式类型** | 有类型注解的变量使用静态类型，无注解的变量退化为 PyObject，兼容动态类型 |
| **编译时检查** | `cypyc` 转译器在编译前进行类型检查，提前发现类型错误 |
| **Cython 后端** | 最终编译目标为 Cython，继承其所有性能优化能力 |
| **简洁语法** | 引入必要的语法糖，保持 Python 的可读性和表达力 |
| **显式内存管理** | 指针变量默认逃逸，需显式使用 `defer` 进行延迟清理 |

### 2.2 转译流程

```
1. 词法分析（Tokenization）
   └── 将源码分解为 token 流（支持自定义关键字）

2. 语法分析（Parsing）
   └── 构建 AST（支持自定义扩展节点：StructDef、TraitDef、ImplStmt 等）

3. 作用域分析（Scope Analysis）
   └── 计算每个节点的缩进层级和作用域，注册变量

4. 类型检查（Type Checking）
   └── 验证类型注解的一致性，推断泛型类型

5. 宏展开（Macro Expansion）
   └── 处理宏定义和宏调用，进行代码替换

6. 代码生成（Code Generation）
   └── 将 AST 转换为 Cython 代码

7. Cython 编译
   └── cythonize → C 代码 → 二进制扩展
```

## 3. 与 Python 的关系

### 3.1 兼容性保证

- **语法兼容**：所有 Python 3.9+ 语法在 Cypy 中均可直接使用
- **标准库兼容**：可直接导入和使用 Python 标准库
- **第三方库兼容**：支持导入任意 Python 第三方库
- **互操作性**：Cypy 模块可导入 Python 代码，Python 代码也可导入 Cypy 编译的模块

### 3.2 增强特性

相对于纯 Python，Cypy 提供以下增强：

| 特性 | 说明 |
|------|------|
| **静态类型** | `x: int = 10` 编译为 `cdef int x = 10` |
| **指针支持** | `ptr: int* = malloc(sizeof(int))` |
| **结构体** | `struct Point: x: float; y: float` |
| **特质系统** | `trait Drawable` + `impl Drawable for Circle` |
| **隐式策略** | `implicit struct Config` |
| **构建块** | `=:`、`~:`、`*:` 语法 |
| **延迟清理** | `defer free(buffer)` |
| **守卫表达式** | `guard x != 0 else 0` |
