# 编译期求值

## 当前实现状态

**注意**：当前版本的 `comptime` 编译期求值功能实现非常有限，以下描述的是实际实现的功能。

### 表达式形式

```python
# comptime 表达式（当前仅解析，不进行实际的编译期求值）
let PI: float = comptime: 3.141592653589793
let MAX_SIZE: int = comptime: 1024 * 1024
```

## 实现说明

当前版本的 `comptime` 实现：

1. **语法解析**：`ComptimeStmt` AST 节点存储编译期表达式
2. **代码生成**：在 `LetStmt` 和 `Assign` 中，`comptime` 表达式被当作普通表达式处理，不会在编译期实际执行
3. **独立语句**：单独的 `comptime:` 语句被转换为注释（`# comptime: ...`）
4. **编译期函数**：`comptime def` 语法未实现

## 使用 `const` 声明编译期常量

虽然 `comptime` 语句未完全实现，但可以使用 `const` 声明来定义编译期常量：

```python
# const 声明会在编译期展开值，生成到 .pyd 文件中
const PI: float = 3.141592653589793
const MAX_SIZE: int = 1024 * 1024

# const 声明的值是只读的，无法修改
```
