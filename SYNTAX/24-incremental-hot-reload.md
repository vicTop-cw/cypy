# 增量编译与热重载

## 增量编译

### 原理

```
┌─────────────────────────────────────────────┐
│              检测文件变更                    │
│  基于 watchdog 库监控 .cypy 文件            │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              AST 差异分析                    │
│  比较新旧 AST，识别变更的定义                │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              依赖图分析                      │
│  构建定义级依赖关系，识别受影响模块          │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              智能重编译决策                  │
│  仅重新编译受影响的模块                      │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              更新缓存                        │
│  更新编译结果缓存，跳过未变更模块            │
└─────────────────────────────────────────────┘
```

### 性能提升

```python
# 增量编译性能对比
# 首次编译：100% 模块
# 变更单个文件后：仅编译该文件及其依赖
# 性能提升：>50%
```

## 热重载

### 原理

```
┌─────────────────────────────────────────────┐
│              文件监控                        │
│  watchdog 检测文件创建/修改/删除            │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              自动重新编译                    │
│  触发增量编译，生成新的 .pyd 文件            │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              代理模块更新                    │
│  CypyProxyModule 切换到新的 .pyd 引用       │
└─────────────────────┬───────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              状态保持                        │
│  模块级状态通过代理保持                      │
└─────────────────────────────────────────────┘
```

### 代理模块模式

```python
class CypyProxyModule:
    """代理模块，解决 Windows .pyd 文件锁定问题"""
    
    def __init__(self, module_name: str):
        self.module_name = module_name
        self._module = None
    
    def _reload(self):
        """重新加载模块"""
        import importlib
        import sys
        
        # 强制重新导入
        if self.module_name in sys.modules:
            del sys.modules[self.module_name]
        
        self._module = importlib.import_module(self.module_name)
    
    def __getattr__(self, name: str):
        """委托属性访问到实际模块"""
        if self._module is None:
            self._reload()
        return getattr(self._module, name)
```

## 命令行使用

### 基本命令

```bash
# 启动热重载开发服务器
cypyc watch ./src

# 指定输出目录
cypyc watch ./src -o ./build

# 自定义防抖延迟（默认 0.5 秒）
cypyc watch ./src --debounce 1.0

# 详细输出
cypyc watch ./src -v
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-d/--directory` | 监控目录 | 当前目录 |
| `-o/--output` | 输出目录 | `__pycache__/cypy` |
| `--debounce` | 防抖延迟（秒） | 0.5 |
| `-v/--verbose` | 详细输出 | False |


### 依赖级联重编译

```python
# A.py 依赖 B.py，B.py 依赖 C.py
# 修改 C.py 时，自动重新编译 C.py → B.py → A.py
# 未受影响的模块保持不变
```

## 注意事项

### 限制

```python
# 热重载限制
# 1. 类定义变更需要重新启动应用
# 2. 全局变量状态可能丢失（通过代理模式保持）
# 3. 大型项目建议使用增量编译而非热重载
```

### 最佳实践

```python
# 开发时使用热重载
# cypyc watch ./src

# 构建生产版本时使用增量编译
# cypyc --compile ./src --profile release

# 测试时使用类型检查
# cypyc --check ./src
```

## 增量编译与热重载特性

| 特性 | 说明 |
|------|------|
| **增量编译** | 仅重新编译修改的模块 |
| **热重载** | 不中断应用运行更新代码 |
| **文件监控** | 基于 watchdog 的文件变更检测 |
| **代理模块** | CypyProxyModule 解决 Windows 文件锁定 |
| **依赖级联** | 自动重新编译依赖模块 |
| **性能提升** | 增量编译 >50% 速度提升 |
| **防抖机制** | 0.5 秒默认防抖延迟 |
