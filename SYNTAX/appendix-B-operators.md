# 附录 B - 操作符参考

> 本附录按类别列出 Cypy 语言中的全部操作符，并给出名称、优先级、语法、说明和示例。
> 操作符来源：`cypyc/parser/lexer.py` 中的 `TokenType` 定义与字符分词逻辑。

## 优先级约定

下表中优先级以数字表示，**数字越大优先级越高**（绑定更紧）。同级运算符按结合性（左/右）求值。仅给出相对优先级；具体解析顺序参见 `cypyc/parser/parser.py` 中的表达式解析函数。

| 优先级 | 类别 |
|--------|------|
| 14 (最高) | `.` 成员访问、`()` 调用、`[]` 索引、`@` 装饰器 |
| 13 | `**` 幂 |
| 12 | `*` `/` `%` |
| 11 | `+` `-` |
| 10 | `<<` `>>` |
| 9 | `&` `^` `\|` |
| 8 | `<` `>` `<=` `>=` `<:` `==` `!=` `is` `in` |
| 7 | `not` |
| 6 | `and` |
| 5 | `or` |
| 4 | `->` `=>` `\|>` 类型/控制 |
| 3 | `=:` `~:` `*:` `^:` `^` 构建块 |
| 2 | `=` `+=` `-=` `*=` `/=` 赋值 |
| 1 (最低) | `,` `:` `;` 分隔符 |

## 1. 算术运算符

## 3. 位运算符

| 运算符 | 名称 | 优先级 | 语法 | 说明 | 示例 |
|--------|------|--------|------|------|------|
| `<<` | 左移 | 10 | `a << n` | 按位左移 | `1 << 4` → `16` |

## 8. 构建块运算符

> 构建块符号必须满足**符号后紧跟换行**才被识别为构建块；否则解析为普通符号组合。

| 运算符 | 名称 | 优先级 | 语法 | 说明 | 示例 |
|--------|------|--------|------|------|------|
| `=:` | 变量构建块 | 3 | `name =:`<br>`    <expr>` | 创建闭包无参函数，绑定到 name；支持 early return 和 guard | `square =:`<br>`    return x * x` |
| `~:` | 调用构建块 | 3 | `name ~:`<br>`    <expr>` | 创建闭包无参函数并立即调用的语法糖 | `result ~:`<br>`    compute(x)` |
| `*:` | 生成器构建块 | 3 | `name *:`<br>`    yield ...` | 创建闭包生成器 | `gen *:`<br>`    yield i` |
| `^:` | 索引构建块 | 3 | `name ^:`<br>`    <expr>` | 创建闭包无参函数（lz 索引模式） | `key ^:`<br>`    hash(x)` |
| `^` | 构建值 | 3（前缀） | `^<expr>` | 在构建块内引用产出值 | `^result` |

参见：`13-build-blocks.md`。

## 操作符速查表

```
优先级（高 → 低）：
  . () [] @                  访问 / 调用 / 索引 / 装饰器
  **                         幂
  * / %                      乘除模
  + -                        加减
  << >>                      移位
  & ^ |                      位运算 / 联合
  < > <= >= <: == != is in   比较 / 子类型
  not                        逻辑非
  and &&                     逻辑与
  or ||                      逻辑或
  -> => |>                   类型 / 箭头 / 管道
  =: ~: *: ^: ^              构建块
  = += -= *= /=              赋值
  , : ;                      分隔符
```

## 备注

1. **构建块符号识别规则**：`=:`、`~:`、`*:`、`^:` 必须**后跟换行**才会被识别为构建块；否则按普通 `=` 和 `:` 解析。`*:` 还要求前置字符为空白。
2. **`*` 的多重身份**：乘法（中缀）、解引用（前缀）、`**` 幂运算、`*:` 生成器构建块。具体含义由上下文决定。
3. **`&` 的多重身份**：按位与（中缀）、取地址（前缀，TokenType.DEREF）。`&&` 是逻辑与。
4. **`|` 的多重身份**：按位或（中缀）、联合类型（类型上下文）、`|>` 管道（与 `>` 组合）。
5. **`^` 的多重身份**：按位异或（中缀）、构建值（前缀）、`^:` 索引构建块（与 `:` 组合且后换行）。
6. **`!` 的多重身份**：作为 `!=` 的一部分、作为后缀宏触发（`name!`）、作为前缀逻辑非（兼容）。
7. **关键字运算符**：`and`/`or`/`not`/`is`/`in`/`as` 在词法层是关键字，但在语法层作为运算符使用，与符号形式 `&&`/`||` 等价（逻辑运算）。
