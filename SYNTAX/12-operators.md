# 操作符

Cypy 支持丰富的操作符集合，包括算术、比较、位操作符，以及管道操作符。

## 算术操作符

| 操作符 | 名称 | 说明 | 示例 |
|--------|------|------|------|
| `+` | 加法 | 数值相加或字符串拼接 | `1 + 2`, `"hello" + "world"` |
| `-` | 减法 | 数值相减 | `5 - 3` |
| `*` | 乘法 | 数值相乘或重复字符串 | `2 * 3`, `"a" * 3` |
| `/` | 除法 | 浮点除法 | `10 / 3` → `3.333...` |
| `%` | 取模 | 求余数 | `10 % 3` → `1` |
| `**` | 幂运算 | 指数运算 | `2 ** 3` → `8` |

```python
let a: int = 10
let b: int = 3
print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a % b)   # 1
print(a ** b)  # 1000
```

## 比较操作符

| 操作符 | 名称 | 说明 |
|--------|------|------|
| `==` | 等于 | 判断两个值是否相等 |
| `!=` | 不等于 | 判断两个值是否不相等 |
| `<` | 小于 | 判断左边小于右边 |
| `>` | 大于 | 判断左边大于右边 |
| `<=` | 小于等于 | 判断左边小于或等于右边 |
| `>=` | 大于等于 | 判断左边大于或等于右边 |

```python
let x: int = 5
let y: int = 10

print(x == y)  # False
print(x != y)  # True
print(x < y)   # True
print(x > y)   # False
print(x <= y)  # True
print(x >= y)  # False
```

## 位操作符

| 操作符 | 名称 | 说明 |
|--------|------|------|
| `&` | 按位与 | 两个位都为1时结果为1 |
| `\|` | 按位或 | 任一位置为1时结果为1 |
| `^` | 按位异或 | 两个位不同时结果为1 |
| `~` | 按位取反 | 反转所有位 |
| `<<` | 左移 | 将位向左移动 |
| `>>` | 右移 | 将位向右移动 |

```python
let a: int = 0b1010  # 10
let b: int = 0b1100  # 12

print(a & b)   # 0b1000  → 8
print(a | b)   # 0b1110  → 14
print(a ^ b)   # 0b0110  → 6
print(~a)      # -11
print(a << 1)  # 0b10100 → 20
print(a >> 1)  # 0b101   → 5
```

## 赋值操作符

| 操作符 | 说明 | 示例 | 等价于 |
|--------|------|------|--------|
| `=` | 赋值 | `x = 5` | - |
| `+=` | 加法赋值 | `x += 3` | `x = x + 3` |
| `-=` | 减法赋值 | `x -= 3` | `x = x - 3` |
| `*=` | 乘法赋值 | `x *= 3` | `x = x * 3` |
| `/=` | 除法赋值 | `x /= 3` | `x = x / 3` |
| `%=` | 取模赋值 | `x %= 3` | `x = x % 3` |
| `**=` | 幂赋值 | `x **= 3` | `x = x ** 3` |
| `<<=` | 左移赋值 | `x <<= 3` | `x = x << 3` |
| `>>=` | 右移赋值 | `x >>= 3` | `x = x >> 3` |
| `&=` | 按位与赋值 | `x &= 3` | `x = x & 3` |
| `\|=` | 按位或赋值 | `x \|= 3` | `x = x \| 3` |
| `^=` | 按位异或赋值 | `x ^= 3` | `x = x ^ 3` |

```python
var x: int = 10
x += 5   # x = 15
x *= 2   # x = 30
x >>= 1  # x = 15
```

## 管道操作符

管道操作符 `|>` 允许将前一个表达式的结果作为后一个函数的第一个参数传递，提高代码可读性。

```python
# 传统方式
def double(x: int) -> int:
    return x * 2

def add_one(x: int) -> int:
    return x + 1

let result = add_one(double(5))  # 11

# 管道方式
let result = 5 |> double |> add_one  # 11
```

### 链式管道

管道操作符支持链式调用：

```python
let data = [1, 2, 3, 4, 5]

# 过滤偶数，平方，求和
let sum_of_squares = data \
    |> filter(lambda x: x % 2 == 0) \
    |> map(lambda x: x ** 2) \
    |> sum
```

## 逻辑操作符

| 操作符 | 名称 | 说明 |
|--------|------|------|
| `and` | 逻辑与 | 两个条件都为真时结果为真 |
| `or` | 逻辑或 | 任一条件为真时结果为真 |
| `not` | 逻辑非 | 反转布尔值 |

```python
let a: bool = True
let b: bool = False

print(a and b)  # False
print(a or b)   # True
print(not a)    # False
```

## 操作符优先级

从高到低排列：

| 优先级 | 操作符 | 结合性 |
|--------|--------|--------|
| 1 | `**` | 右 |
| 2 | `~`, `-` (一元) | 右 |
| 3 | `*`, `/`, `%` | 左 |
| 4 | `+`, `-` | 左 |
| 5 | `<<`, `>>` | 左 |
| 6 | `&` | 左 |
| 7 | `^` | 左 |
| 8 | `\|` | 左 |
| 9 | `<`, `<=`, `>`, `>=` | 左 |
| 10 | `==`, `!=` | 左 |
| 11 | `|>` | 左 |
| 12 | `not` | 右 |
| 13 | `and` | 左 |
| 14 | `or` | 左 |
| 15 | `=`, `+=`, `-=` 等 | 右 |

## 操作符重载

Cypy 支持通过魔法方法重载操作符。以下是常用的操作符重载方法：

| 操作符 | 魔法方法 |
|--------|----------|
| `+` | `__add__` / `__radd__` |
| `-` | `__sub__` / `__rsub__` |
| `*` | `__mul__` / `__rmul__` |
| `/` | `__truediv__` / `__rtruediv__` |
| `%` | `__mod__` / `__rmod__` |
| `**` | `__pow__` / `__rpow__` |
| `==` | `__eq__` |
| `!=` | `__ne__` |
| `<` | `__lt__` |
| `>` | `__gt__` |
| `<=` | `__le__` |
| `>=` | `__ge__` |

```python
struct Vector:
    x: float
    y: float
    
    def __add__(self, other: Vector) -> Vector:
        return Vector(x=self.x + other.x, y=self.y + other.y)
    
    def __mul__(self, scalar: float) -> Vector:
        return Vector(x=self.x * scalar, y=self.y * scalar)
    
    def __eq__(self, other: Vector) -> bool:
        return self.x == other.x and self.y == other.y

let v1: Vector = Vector(x=1.0, y=2.0)
let v2: Vector = Vector(x=3.0, y=4.0)
let v3: Vector = v1 + v2  # Vector(4.0, 6.0)
let v4: Vector = v1 * 2   # Vector(2.0, 4.0)
print(v1 == v2)           # False
```
